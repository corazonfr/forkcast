# Forkcast

Ends the "where should we eat?" argument. Everyone adds what they like and what they won't eat, Forkcast picks a nearby restaurant the whole group is happy with, then sends you to that place on DoorDash or Uber Eats (or gives you directions).

**Open it:** https://corazonfr.github.io/forkcast/

- One nope from anyone rules a place out; likes push places up.
- Spin again, or run a family vote between three finalists.
- Remembers your family and recent picks on this device only (browser storage). Nothing is sent anywhere else.

Built from free APIs listed in [public-apis](https://github.com/public-apis/public-apis):
OpenStreetMap (Nominatim and Overpass) for restaurants, TheMealDB for dish photos, Open-Meteo for weather.

Run locally: double-click `Start Forkcast.bat` (serves on http://localhost:8793).
